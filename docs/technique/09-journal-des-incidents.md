# 9. Journal des incidents

Démarche suivie pour chaque incident : constater et décrire le symptôme ; reproduire (test automatisé quand c'est possible) ; chercher la cause à partir des journaux, du code et de la documentation ; corriger sur une branche `fix/*` ; vérifier par le test qui reproduisait l'incident, puis par la CI ; consigner ici. La procédure des anomalies est décrite au §9 de [`docs/tests/plan-de-tests.md`](../tests/plan-de-tests.md).
